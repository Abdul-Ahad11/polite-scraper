# Polite Scraper

## Stage 0 — Target Classification

### Target Website

The target website for this scraping project is:

https://books.toscrape.com/

Books to Scrape is a fictional bookstore website provided as a sandbox for practicing web scraping.

### Scope

The scraper will work only with the first three catalogue pages:

1. https://books.toscrape.com/catalogue/page-1.html
2. https://books.toscrape.com/catalogue/page-2.html
3. https://books.toscrape.com/catalogue/page-3.html

These three catalogue pages contain 60 book listings in total.

### Data to Collect

The scraper will collect book information from the individual book pages, including:

- Book title
- Price
- Availability

The extracted data will be cleaned and validated in the later stages of the project.
